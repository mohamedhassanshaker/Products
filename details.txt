The Docker Compose stack is refreshed and verified working end-to-end, including the Platform Manager console:

What changed: The console was previously unreachable in this compose setup at all — web's IP-allowlist check never trusts forwarded-IP headers unless a real proxy sits in front of it and overwrites them, and web was published directly with no proxy. Fix: added a small web-proxy (nginx) service that's now the only thing publishing web's port, always overwrites X-Forwarded-For/X-Real-IP with its own real connection, and sits on a pinned Docker subnet so the resulting caller IP is deterministic. The allowlist/trusted-proxy env vars now default to that pinned address, and a real operator token is generated by default — all three documented alongside your other seeded credentials in SEED_CREDENTIALS.md.
