## Phase Summary

- **Phase 1 (P0 core loop):** BL-01 → BL-07, plus BL-26 — auth/RBAC, MCP connector +
  tool discovery/catalog/permissions, widget shell, platform branding/white-label
  theming, Tier-1 autonomous tool calls with structured rendering, conversation
  persistence/trace, and the Agent Platform Architecture foundation (registry/eval/
  model gateway/observability) running underneath it from day one.
- **Phase 2 (P0 safety/trust completion):** BL-08 → BL-11 — Tier-2/3 approval flows,
  human escalation, audit/PII/data-residency controls, and MCP/runtime health
  monitoring — completes what the spec considers MVP-viable.
- **Phase 3 (P1 expansion):** BL-12 → BL-18 — multi-step workflows, deployment/canary
  management, voice/IVR and Meta channel expansion, Conversation Designer Studio,
  core reporting, Developer Portal.
- **Phase 4 (P1 fast-follow):** BL-19 → BL-23 — code-first agent builder, A2A
  interoperability, SLA passthrough reporting, Gateway Agent (on-prem), and
  engagement/QoL features (CSAT, nudges, agent performance dashboard).
- **Phase 5 (P2, post-launch):** BL-24 — Campaign Manager, built fresh per user
  decision (2026-08-15). Growth Tools (formerly BL-25) was deprecated by user decision
  on the same date and removed from the backlog entirely — see
  PRODUCT_SPECIFICATION.md §9.4.
- **Phase 6 (P0, Blueprint Phase 0 — 2026-08-28):** BL-27 → BL-31 — five small,
  independently-shippable items closing currently-live severity-1/2 gaps: emergency
  rollback, capability-group management, MCP manifest pinning/drift quarantine,
  tool-result injection guardrail, and Git-independent structural YAML diff. No
  dependency among them; all rank ahead of every later Blueprint item.
- **Phase 7 (mostly P0, Blueprint Phase 1):** BL-32 → BL-36 — Model Gateway v2
  (provider registry, model catalog, routes, usage/cost, residency/plan-tier
  governance), the MCP enrolment wizard/registry, the Skills library, and SSO/SCIM.
  Model Gateway v2 (BL-32/33) is the hard, non-negotiable prerequisite for Phase 8's
  Knowledge subsystem.
- **Phase 8 (P0 gate + P1 modules, Blueprint Phase 2):** BL-37 → BL-45 — the
  permission-intersection evaluator and delegation trace tree (BL-37, a P0 hard gate
  on Phase 9's teams, built early rather than deferred), Knowledge and Graph RAG
  end-to-end (ingestion, graph explorer, retrieval strategies, bounded retrieval
  agent, governance), the Agent Design Studio, eval harvesting/judge grading, and
  escalation workforce mechanics (assignment/SLA/presence/CSAT).
- **Phase 9 (P1, Blueprint Phase 3):** BL-46 → BL-47 — Multi-agent orchestration
  (agent-as-tool registration, supervisor/specialist teams) and the Workflow Designer
  (static orchestration graph, durable runtime). Both gated on Phase 8's permission
  evaluator/trace tree and Phase 7's Skills library.
- **Phase 10 (P2, Blueprint Phase 4):** BL-48 → BL-52 — progressive rollout/shadow
  evaluation/canary, the public API/webhooks/OpenTelemetry/SIEM export, cross-channel
  identity resolution, configuration export/restore, and consented break-glass
  operator access. Lowest urgency; several depend on module boundaries stabilizing
  across Phases 6–9 first.

See `docs/PRODUCT_SPECIFICATION.md` §7.4 for the full rationale table mapping these
five new phases to Blueprint sections, and §9.5 for the open questions
(`docs/blueprint/NextBot-Target-Architecture-Blueprint.md` §14.2) that
